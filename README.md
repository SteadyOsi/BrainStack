# BrainStack

BrainStack is a developer playground built around experimentation, learning, and building real software.

The project originally started from an interest in hardware emulation, but has expanded into a broader sandbox for full stack development, frontend experimentation, tooling, and systems programming concepts.

This repository acts as both:

* A learning environment
* A portfolio project
* A long-term experimental workspace
* A place to prototype ideas quickly

---

# Goals

The goal of BrainStack is to combine multiple areas of software development into one evolving project.

Areas explored include:

* Frontend development
* UI/UX experimentation
* TypeScript and JavaScript development
* Angular applications
* Emulator-related concepts
* Systems programming ideas
* API integration
* Automation tooling
* General software engineering practice

Rather than being a single-purpose application, BrainStack is designed to grow organically as new ideas and technologies are explored.

# Getting Started

## Clone the repository

```bash
git clone https://github.com/SteadyOsi/BrainStack.git
```

## Navigate into the project

```bash
cd BrainStack
```

## Install dependencies

```bash
npm install
```

## Run the development server

```bash
ng serve
```

Then open:

```text
http://localhost:4200
```
